# v0.4.0

This release drops Python 3.10 and moves to a patched filelock.

## Breaking

- Python 3.11 or newer is required. Python 3.10 reached end-of-life in October 2026, and the patched filelock release does not support it. Users on Python 3.10 can stay on v0.3.0.

## Security and compatibility

- Require filelock 4.2.1 or newer. Earlier versions from 3.20.4 have a local file-overwrite vulnerability in `ReadWriteLock`. This server reaches filelock only through arxiv-to-prompt, which uses `FileLock` and not `ReadWriteLock`, so earlier releases were not exposed; the floor keeps the affected versions out of installs.
- The desktop extension installs the patched filelock on its next launch, because its dependency requirements changed.
- CI and release tests run on Python 3.11, 3.12, and 3.13.

## Install or upgrade

- PyPI: `python -m pip install --upgrade arxiv-latex-mcp`
- uvx: `uvx --refresh arxiv-latex-mcp`
- Claude Desktop extension: download and install `arxiv-latex-mcp.mcpb` from this release. Python 3.11+ with pip and internet access are needed for the first launch after installation or a dependency/runtime update. Later launches reuse the installed dependencies.

Restart your MCP client after upgrading.

Full changes: https://github.com/takashiishida/arxiv-latex-mcp/compare/v0.3.0...v0.4.0
