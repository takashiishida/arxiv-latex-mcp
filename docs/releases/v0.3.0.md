# v0.3.0

This release adds arXiv search and improves paper retrieval, caching, and dependency security.

## Added

- `search_papers`: search arXiv by query, with date filters, sorting, and result limits. Results include paper metadata and links.
- MCP server instructions that explain tool selection and paper identifiers to clients.
- A reproducible desktop extension build and release checks for matching versions, dependency requirements, and passing tests.

## Improved

- Reuse cached LaTeX sources. Unversioned papers refresh after seven days by default; versioned paper IDs keep their cached source. Cache settings are configurable through environment variables.
- Clearer errors for PDF-only papers, invalid identifiers, unreachable arXiv services, and missing abstracts or sections.
- Section retrieval uses section titles and nested title paths.
- Search requests encode queries correctly, share request throttling, and preserve legacy arXiv identifiers.

## Security and compatibility

- Require MCP 1.30.0 or newer, PyJWT 2.15.1 or newer, urllib3 2.8.0 or newer, and certifi 2026.10.19 or newer to address known dependency advisories.
- Keep MCP below 2.0 for compatibility with the current server API.
- The desktop extension installs wheels into its own dependency cache. It refreshes that cache when requirements or the Python runtime change, ignores legacy/global dependency installations, and stops if installation fails.
- Include Apache-2.0 attribution and license text for the adapted search functionality.

## Install or upgrade

- PyPI: `python -m pip install --upgrade arxiv-latex-mcp`
- uvx: `uvx --refresh arxiv-latex-mcp`
- Claude Desktop extension: download and install `arxiv-latex-mcp.mcpb` from this release. Python 3.10+ with pip and internet access are needed for the first launch after installation or a dependency/runtime update. Later launches reuse the installed dependencies.

Restart your MCP client after upgrading.
